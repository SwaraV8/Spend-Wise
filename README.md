# SpendWise

SpendWise is a simple, responsive personal finance dashboard made with
**HTML and CSS**. It provides a clean layout to view income, expenses,
budgets, transactions, and savings.

## Pages

-   `index.html` -- Dashboard with balance, monthly income, expenses,
    and recent transactions.
-   `transactions.html` -- List of sample transactions.
-   `add.html` -- Form layout for adding an income or expense.
-   `budget.html` -- Monthly budget and expense breakdown.
-   `savings.html` -- Savings goal and preference settings.
-   `style.css` -- Shared styling and responsive layout for all pages.

## How to Run

1.  Keep all the files in the same folder.
2.  Open `index.html` in any web browser.
3.  Use the navigation links to move between pages.

## Note

This is a front-end demo. The information is sample content; forms and
settings do not save or update data because the project does not use
JavaScript or a backend.
